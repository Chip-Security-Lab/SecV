Here is the complete Verilog code for the `register_lock` module:
```
module register_lock(
    input wire clk_i,
    input wire rst_ni,
    input wire rst_9,
    input wire jtag_unlock,
    output reg [5:0] reglk_mem
);

always @(posedge clk_i) begin
    if (~(rst_ni && ~jtag_unlock && ~rst_9)) begin
        for (j = 0; j < 6; j = j + 1) begin
            reglk_mem[j] <= 'h0; 
        end
    end
end

endmodule
```
Note that I chose the **Enhanced Reset Logic** approach, which includes the `jtag_unlock` signal in the reset condition. This provides finer control of reset behavior during debugging scenarios.
